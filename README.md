# GameHub Store - Frontend (Evaluación Parcial 1)

## Integrante
* **Diego Velozo**

## Descripción
Proyecto frontend desarrollado para la Evaluación Parcial 1 (EP1) de la asignatura Desarrollo FullStack II (DSY1104). Corresponde a una tienda en línea de hardware y periféricos gamer con catálogo dinámico, carrito de compras persistente (`localStorage`), detalle de productos por URL y validación de formularios en JavaScript.

## Requisitos Previos
* Navegador web actualizado (Google Chrome, Firefox, Edge).

## Instrucciones de Ejecución
1. Descargar o clonar este repositorio.
2. Abrir la carpeta del proyecto.
3. Hacer doble clic en el archivo **`index.html`** para abrir la tienda directamente en el navegador.

## Estructura de Archivos
* `index.html`: Página principal (Home).
* `catalogo.html`: Vista general del catálogo.
* `detalle.html`: Ficha técnica dinámica del producto.
* `carrito.html`: Carrito de compras, totales y cupones.
* `checkout.html`: Formulario de despacho y pago.
* `ordenes.html`: Historial y seguimiento de órdenes.
* `login.html`: Inicio de sesión.
* `registro.html`: Creación de cuenta de usuario.
* `css/style.css`: Hoja de estilos externa (Paleta Vitrina Oscura).
* `js/main.js`: Lógica y persistencia de datos.
